# MidMeet

CS 3354 Software Engineering, Fall 2026 · Team 3, Section 005

## Project Summary

MidMeet helps two friends choose a fair place to meet. You type in both
start addresses and pick a type of place (such as a coffee shop, restaurant or
park). MidMeet then suggests real, named places where the driving time is as
close to equal as possible for both people, and shows each person's drive in
minutes on a map.

This first release covers two people and driving time only. Other travel
modes, groups of three or more, and reservations are out of scope for now.

This repository currently holds our P1 deliverable (proposal and requirements).
The full document is in `docs/P1/`.
