Spike S-01 was created to create a prototype that answers a simple question. 

'Can one search 2 addresses, find places near the midpoint and get drive time/routes in under 5 seconds using a Google Maps API key for no cost?'

Through trial and error and the assistance of Claude, it was revealed that a minimum $30 charge is needed to use a Google Maps API key for geocoding, routes, and places. There is a strong hesitancy to tie personal banking information to an API key for a group project for school by group member, Nicholas Jackson. Further discussion needs to take place on API key use before testing can proceed. The code in MidMeet_Spike01.py appears to be functional, but cannot be confirmed until a functional API key can be used. 

The simple answer to our is question is that one CANNOT search 2 addresses, find places, and get drive times in under 5 seconds using a Google Maps API key for no cost. It fails because there is a minimum $30 cost included in the creation of a Google Maps API key. 

The group will further discuss how to approach this problem and will work on finding a solution to keep the project progressing.
